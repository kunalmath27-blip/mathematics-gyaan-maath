# Mathematics Gyaan Maath

An installable mathematics teaching workspace for Class 9–12 and IIT JEE.

- S Pen only mode, pressure-aware pens, erasers and lasso editing
- PDF, photo and personal PYQ question library
- Graphs with parameter sliders, annotated geometry and illustrations
- Zoom, paper styles, ruler, protractor, laser and class timer
- Board and microphone recording, video downloads, notebook backup
- Offline tools after the first online load shows **Offline ready**

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. This is a static website and needs no paid hosting plan or build command.

## Use on a tablet

Open the published site in current Chrome, keep **S Pen only** enabled, and choose **Install app** or Chrome's **Add to Home screen**. Pen pressure, hover, tilt and side-button support depend on the device and browser.

## Local work and backups

Notebooks, questions and recordings are stored locally in the browser on each device. They are not included in this repository and do not sync between different website addresses. Export a notebook backup and download recordings before moving from another address or clearing browser data.

## PDF rendering

The bundled PDF.js 4.10.38 and standard fonts retain their upstream Apache-2.0 and font licenses under `vendor/pdfjs/`.
